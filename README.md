# 배터리 열폭주 단계 분류

배터리를 가열하거나 과충전하는 실험에서 5 ~ 15초 간격으로 측정한 센서 값과 열화상 이미지로 각 시점의 열폭주 단계(1 ~ 6)를 예측한다. 최종 모델의 Public Macro F1은 **0.8946**이다.

모델은 한 시점의 센서 값에 더해 그때까지의 변화율, 최고값, 주요 이벤트 발생 시점을 입력으로 사용한다. 예를 들어 표면 온도가 200℃인 시점은 온도가 상승하는 중일 수도, 최고점을 지나 내려오는 중일 수도 있다. 누적 최고 온도와 최고점 이후 경과 시간을 함께 입력하면 두 상황을 구분할 수 있다.

| 입력 | 개수 | 내용 |
|---|---:|---|
| 센서 및 실험 조건 | 17 | 전압, 온도, 압력, 가스 농도, 배터리 종류·용량·충전 상태·실험 방식 |
| 시계열 파생변수 | 50 | 최근 30·120초 변화율, 누적 최고값, 전압 급락·가스 발생 이후 경과 시간 등 |
| 단계 전환 신호 | 33 | 표면 온도 45℃ 돌파, 최고 전압 대비 1/6 하락, 급가열, 온도 정점 이후 하락 등 |
| 이미지 밝기 통계 | 6 | 흑백 밝기의 평균·표준편차·최댓값·95/99 백분위수·고휘도 픽셀 비율 |

총 106개 입력으로 LightGBM 하나를 학습한다. 각 행의 예측 단계에는 실험별 시간순 누적 최댓값을 적용한다. 이 단계 보정은 현재까지 예측한 단계만 사용한다.

## 실행

Python 3 환경에서 다음을 실행한다. 학습과 예측에는 CPU를 사용한다.

```bash
pip install -r requirements.txt
python test.py --input <CSV> --image_root <이미지 폴더> --output final.csv
```

`test.py`는 저장된 `weights/lgbm106.joblib`을 불러와 예측한다. `--image_root`에는 `.../test/images` 또는 `.../test`를 지정할 수 있다.

가중치를 다시 만들거나 Validation 결과를 확인하려면 다음 명령을 사용한다.

```bash
python train.py --data_dir <battery_data_light 폴더>
python train.py --data_dir <battery_data_light 폴더> --validate
```

첫 번째 명령은 Train과 Validation으로 학습한 가중치를 저장한다. `--validate`는 Train으로 학습해 Validation을 평가하며 가중치를 저장하지 않는다.

| 파일 | 역할 |
|---|---|
| `model.py` | 센서·이미지 피처 계산, 학습·예측, 단계 보정 |
| `train.py` | 학습 및 가중치 저장 |
| `test.py` | 저장된 가중치로 제출 CSV 생성 |
| `weights/lgbm106.joblib` | 모델, 범주 값 대응표, 입력 열 이름과 순서 |

주요 패키지는 numpy, pandas, scikit-learn, lightgbm, joblib, pillow다.

## 피처 설계

`relative_time_s`는 모델 입력에서 제외하고 시간순 정렬과 변화율 계산에만 사용한다. 입력에서 제외했을 때 Public 점수는 0.8642에서 0.8739로 올랐다. 실험별 가열 속도가 달라 경과 시간 자체보다 센서 변화가 단계 판단에 도움이 됐다.

학습 데이터에서 1→2단계는 표면 온도 45℃, 3→4단계는 최고 전압 대비 약 1/6 하락과 강하게 맞물렸다. 이를 단순한 판정 규칙으로 적용하는 대신, 기준을 넘었는지와 넘은 뒤 몇 초가 지났는지를 모델 입력에 추가했다. 5→6단계에는 정점 대비 온도 하락량과 비율을 사용했다. 이 33개 피처를 추가했을 때 교차검증은 0.8968에서 0.9066, Public은 0.8739에서 0.8861로 올랐다.

열화상 이미지는 흑백 밝기 통계 6개로 요약한다. 실험마다 촬영 구도와 색 범위가 달라 이미지 표현을 더 복잡하게 만든 실험은 일반화 성능이 안정적이지 않았다.

시계열 피처는 `experiment_id`별로 `relative_time_s` 순서에 따라 계산하고 결과를 원래 행 순서로 되돌린다. 누적 최고값, 첫 관측값, 이벤트 이후 경과 시간, 실제 초 단위 변화율은 현재와 이전 관측만 사용한다. 계산할 수 없는 값은 NaN으로 두어 LightGBM에서 처리한다. 실험 전체 길이나 미래 관측값을 사용하는 피처는 없다.

## 학습과 검증

| 구분 | 행 수 | 실험 수 | 용도 |
|---|---:|---:|---|
| Train | 33,522 | 78 | 모델 구성 선택 시 학습 |
| Validation | 10,200 | 19 | 모델 구성 평가, 최종 학습에 포함 |
| Test | 3,451 | 11 | 최종 예측 |

구성 선택에는 Train으로 학습하고 Validation으로 평가했다. Validation은 원본 5초 간격과 10초·15초 간격으로 솎은 데이터의 Macro F1을 평균했다. 추가로 Train과 Validation의 97개 실험을 실험 단위로 나누어 5-fold 교차검증을 두 번 수행했다. 같은 실험의 관측이 학습과 평가에 동시에 포함되지 않도록 했다.

Test의 10초·15초 측정 간격에 대응하기 위해 학습 실험도 2행 또는 3행 중 하나씩 남긴 복사본을 추가했다. 각 복사본은 솎은 시계열에서 파생변수를 다시 계산한다. 최종 가중치는 구성을 정한 후 Train과 Validation 전체로 학습했다.

LightGBM 설정은 나무 300개, 학습률 0.05, `colsample_bytree=0.5`, `subsample=0.8`, `subsample_freq=1`, `class_weight='balanced'`다. 단계 보정은 실험별 예측 단계의 누적 최댓값이다. 한 번 높은 단계를 잘못 예측하면 이후에도 그 단계가 유지되는 한계가 있다.

| 평가 | Macro F1 |
|---|---:|
| Validation, 5·10·15초 간격 평균 | 0.9078 |
| 실험 단위 교차검증, 10회 평균 | 0.9111 |
| Public 리더보드 | 0.8946 |

Validation 단계별 F1은 1단계 1.000, 2단계 0.848, 3단계 0.946, 4단계 0.822, 5단계 0.916, 6단계 0.916이다. 오답은 주로 2·3단계 전환 부근에 집중됐다. 관찰한 센서 신호에서 이 전환을 안정적으로 가르는 단일 기준은 찾지 못했다.

## 추가 실험

| 시도 | 관찰 결과 |
|---|---|
| 사전학습 ResNet18 이미지 특징 추가 | Validation +0.0017, Public −0.0200 |
| 이미지 CNN·GRU의 확률 결합 | +0.0002~0.0003 수준 |
| 작은 MLP의 확률 결합 | 교차검증 −0.0006 |
| 단계 경계 전용 분류기 | 일부 검증에서 +0.0018, 일관성 부족 |
| 전환 시점을 조정하는 조건별 규칙 | Validation +0.0285, 교차검증 −0.0091 |
| 단계별 가중치 및 추가 파생변수 | 평가 구성에 따라 효과의 방향이 달라짐 |

작은 개선 폭은 실험을 나누는 방법에 민감했다. 최종 구성에는 여러 평가에서 개선이 확인된 피처와 LightGBM만 반영했다. 사전학습 모델은 최종 예측에 사용하지 않는다. Test는 모델 학습과 전처리 기준 산출에 사용하지 않는다.
